# Droplet 记账 — 产品需求规格说明（PRD v1.0）

- **应用名称**：Droplet 记账
- **代码仓库**：`https://github.com/kvtttba/droplet`（Public）
- **目标平台**：Android 单端，最低支持 **Android 12（API 31）**
- **使用定位**：个人自用、无账号/无登录、本地离线优先、纯净无广告、追求 UI 美观与高效率操作
- **文档状态**：v1.0 已确认（需求澄清定稿）

---

## 1. 产品定位与核心原则

1. **隐私与数据主权**：不依赖任何自有后端服务器，无注册登录流程；账本数据全部保存在本地，借助系统生物识别/锁屏密码做访问保护，并通过用户自持的 WebDAV 服务完成加密备份与恢复。
2. **底层严谨、前端顺手**：底层严格遵循**复式记账法**，保证任何时候资产、负债与收支账目恒平；前端默认采用类似「一木记账」的直观记账体验，高频日常记录可在数秒内完成，复杂流水再按需展开专业分录模式。
3. **非侵入式智能记账**：不做无障碍服务或通知栏监听类自动抓账，避免权限侵入与耗电；通过可自定义 `BaseURL` 与 `API Key` 的 AI 能力，重点打通**图片识别、语音识别、一句话自然语言记账**，所有识别结果均先预览确认再入账。
4. **单账本 + 多标签**：不引入多账本隔离复杂度，通过统一的**单账本**配合灵活的**多标签（Tags）**实现场景归类（如旅游、装修、出差、固定开支等）与跨维度统计。
5. **审美与手感优先**：基于 Android 12+ Material 3（Material You）设计语言，支持动态取色与深浅色模式，注重排版呼吸感、清晰的数字层级与单手高频操作可达性。

## 3. 功能需求详细规格（一期 MVP）

### 3.1 安全认证与隐私保护

- **本地鉴权**：App 冷启动时通过 Android `BiometricPrompt` 鉴权，支持指纹 / 人脸，并支持设备锁屏密码（PIN / 图案 / 密码）作为系统级兜底。
- **切后台自动重锁**：支持配置切后台超时重锁时长（如立即 / 30 秒 / 1 分钟 / 5 分钟 / 关闭）。
- **防截屏与多任务遮罩**：支持开启 `FLAG_SECURE`，防止后台多任务预览卡片暴露账单内容（设置内可开关）。
- **金额一键隐身**：首页与资产页顶部提供眼睛图标，一键将全部金额替换为 `****`，状态可持久化。

### 3.2 账户与多币种管理

- **账户类型**：
  - **现金**（人民币/外币现钞）
  - **储蓄卡 / 活期账户**（银行借记卡、支付宝余额、微信零钱等）
  - **信用账户**（信用卡、花呗、白条等）：支持设置**信用额度、账单日、还款日**，自动计算当前已用额度、可用额度、本期应还，并支持到期前 N 天发送本地还款通知提醒。
  - **储值账户**（交通卡、饭卡、电商礼品卡/预付卡等）
  - **投资资金户 & 投资持仓账户**（见 3.4）
  - **分期贷款负债账户**（见 3.5）
  - **往来借贷 & 待报销账户**（见 3.6）
- **通用账户属性**：名称、自定义图标与颜色、所属币种、初始余额（通过期初权益平衡）、排序、归档/隐藏、**是否计入总资产**开关（如医保卡、公积金等可排除在可支配总资产外）。
- **多币种支持（CNY / USD / HKD）**：
  - 主显示币种（本位币）默认 **CNY**，可在设置中切换。
  - 自动从免费公开汇率源每日更新 CNY / USD / HKD 汇率，支持手动点击刷新。
  - 记账时默认采用账户币种；跨币种消费或换汇时自动带入最新参考汇率，并允许手动修改为银行实际成交汇率（或直接填入「转出金额 + 实际到账金额」由系统反推汇率）。
  - 历史收支报表按交易发生时锁定的本位币金额统计，不因后续汇率波动篡改历史账单；外币资产当前估值按最新汇率实时折算。

### 3.3 复式记账核心与日常记账

- **前端直观表单（默认）**：
  - **支出**：选分类、付款账户、金额、时间、标签、商户/备注、可选票据图、可选「待报销」开关、可选优惠/手续费。
  - **收入**：选收入分类、收款账户、金额、时间、标签、备注。
  - **转账 / 还款**：转出账户 → 转入账户，支持手续费录入与跨币种实付/实收金额录入。
  - **借贷 / 报销 / 退款 / 投资**：提供各自专用引导表单，降低复式记账认知门槛。
- **专业分录模式（进阶展开）**：
  - 在记账页可一键切换/展开「多拆分录」，自由增减借方/贷方分录行，实时校验借贷差额，归零后即可保存（适用于工资单拆实发 + 五险一金 + 个税、一次购物跨分类拆分、代金券 + 实付混合支付等场景）。
- **分类与标签体系**：
  - 内置常用支出/收入**二级分类**（大类 + 小类）与精美图标，支持完全自定义增删改排序。
  - 支持一笔交易关联**多个标签**（自定义标签名与颜色），支持在流水页与统计页按单/多标签筛选。

### 3.4 资产管理与行情净值更新

- **覆盖品类（全部纳入一期）**：
  1. **A 股**
  2. **公募基金**
  3. **ETF**
  4. **港股**
  5. **美股**
  6. **贵金属 / 黄金**（如国内金价 AU9999 / 国际金价 XAU）
  7. **加密货币**（如 BTC / ETH / USDT 等主流币种，支持最高 8 位小数份额精度）
  8. **定期存款**
  9. **银行理财**
- **投资记账能力（进阶持仓模式）**：
  - 支持记录**买入、卖出、定投、分红（现金分红）**流水，资金自动与对应资金账户联动。
  - 自动计算并展示：**持仓份额、加权平均成本价、持仓成本、最新单价/净值、当前市值（原币种 + 本位币）、当日涨跌额/涨跌幅、累计浮动盈亏与收益率**。
- **行情与净值更新策略**：
  - **触发机制**：打开资产页时按需刷新（带节流防频繁请求）+ `WorkManager` 后台定时更新（用户可配置更新频率与是否仅 Wi-Fi 更新）+ 手动下拉强制刷新。
  - **公开数据源与降级**：客户端直连免费公开行情源（优先国内可直连接口如东方财富 / 天天基金 / 腾讯财经等，海外品类配备用公开源，并在设置预留可选 HTTP/SOCKS 代理配置）；任意标的拉取失败时保留最近一次缓存净值并清晰标注「上次更新时间」，同时**支持手动覆写单价/净值**。
  - **定期存款与银行理财特殊处理**：
    - **定期存款**：录入本金、起息日、存期、约定年利率及计息规则，本地按天自动计算当前应计利息与到期预期本息。
    - **非标准化银行理财**（无统一公开净值 API）：支持手动录入最新净值或最新收益金额（后续也可通过 AI 截图更新）；若存在公开可查代码则走标准净值更新。

### 3.5 分期贷款管理

- **支持类型**：
  - **等额本息**（房贷 / 车贷 / 消费贷）
  - **等额本金**（房贷 / 车贷）
  - **信用卡 / 消费按期固定手续费分期**（花呗分期、信用卡账单/商品分期等）
- **核心流程**：
  - 新建分期贷款时配置总本金、期数、年利率或每期手续费、首期还款日、每月扣款日、关联付款账户，系统自动生成完整**逐期还款计划表**（每期本金、利息/手续费、剩余本金）。
  - **到期处理**：支持配置到期前本地通知提醒；到期日可自动生成（或生成待确认提醒）对应复式还款分录——**本金部分冲减贷款负债，利息/手续费计入利息支出**，付款账户扣除当期应还总额。

### 3.6 借贷管理、待报销与退款

- **借贷管理**：
  - 按**往来人（对象）**聚合查看「别人欠我（应收）」与「我欠别人（应付）」余额明细。
  - 支持**借出、借入、单次或分次收款/还款、约定还款日本地提醒、附加利息收入/支出、坏账核销**（无法收回的欠款一键转为坏账支出平账）。
- **待报销管理**：
  - 记支出时可勾选「待报销」（关联报销对象/备注），底账记入应收待报销资产，**不虚增个人真实消费**。
  - 在资产页「待报销」列表中可单笔或批量勾选确认报销到账：全额到账冲平待报销；若实际报销少于垫付，差额可一键转为个人自付支出。
- **关联退款**：
  - 在任意已有支出详情页点击「退款」，支持**全额退款、部分退款及多次退款**；退款记录与原支出双向关联，自动重算该笔支出与对应分类的**净支出金额**。

### 3.7 AI 智能记账（图片 / 语音 / 一句话文本）

- **统一原则**：
  - **全部先入预览草稿**：无论通过图片、语音还是文本解析，均先展示结构化草稿列表（高亮低置信度或待补充字段），用户核对/微调后一键确认入账。
  - **隐私最小化**：发送给外部 AI 的 Prompt 仅附带用户的账户名称列表、分类名称列表与常用标签名用于精准匹配，**绝不上传账户余额、卡号或历史账单明细**。
  - **离线与失败降级**：无网、接口超时或解析失败时，允许将原图 / 语音转写文本暂存至「待解析草稿箱」，联网后一键重新发起 AI 解析，或直接转人工编辑。
- **图片识别记账**：
  - 支持场景：① 消费小票 / 发票拍照（提取商户、总金额、时间、推荐分类，不强制逐行拆分商品明细）；② 单张微信 / 支付宝 / 银行支付截图；③ **多笔账单列表长截图 & 批量多图导入**（一次拆出多笔待确认草稿）。
  - 入口：App 内拍照 / 相册多选 + **Android 系统分享菜单直达**（在微信/相册点「分享」选 Droplet 记账直接进入识别页）。
- **语音识别记账**：
  - 支持两种转写引擎在设置中自由切换：
    1. **自定义 AI 语音/多模态接口**（如 OpenAI Whisper 兼容 `/audio/transcriptions` 或原生支持音频输入的多模态模型）；
    2. **Android 系统语音输入**转文字后再交给文本 LLM 拆单（离线可用、零额外模型体积）。
  - 支持一句话包含单笔或多笔交易（如「早饭8块微信，中午打车25刷招行信用卡」自动拆为 2 笔草稿）。
- **一句话文字记账**：
  - 提供自然语言快捷输入框，复用文本 LLM 解析链路，自动拆分为单笔或多笔结构化草稿。
- **AI 服务配置（OpenAI Compatible）**：
  - 支持用户自定义 `BaseURL`、`API Key` 与 `Model` 名称。
  - 支持「统一一套默认配置」或「视觉（图片）/ 文本 / 语音 分别独立指定端点与模型」。
  - 提供「连通性测试」按钮，验证配置是否可用。

### 3.8 预算、周期记账与快捷模板

- **预算管理**：支持设置月度 / 年度总预算与各支出分类预算；首页/统计页可视化展示已用比例与剩余日均可用额度；达到预警阈值（如 80% / 100%）时触发本地提醒。
- **周期记账**：支持按天 / 周 / 月 / 年自定义规则（如房租、固定工资、会员订阅、定投），可配置到期自动入账或生成待确认条目，并支持暂停/终止规则。
- **快捷模板**：将高频消费（如通勤地铁、固定午餐）保存为模板，一键填入全部预设字段或直接入账。

### 3.9 统计报表与数据导出

- **统计维度**：支持按月、按年、自定义日期区间统计，并支持按**标签**与**币种/本位币**筛选。
- **图表清单（一期）**：
  - 收支趋势图（按日/月柱状或折线对比）
  - 支出 / 收入分类占比环形图与明细排行榜（可下钻查看具体流水）
  - 净资产 / 总资产 / 总负债历史走势图
  - 收支日历视图（按日直观展示每日净收入/支出，点击查看当日明细）
- **数据导出**：支持按时间范围或全量导出为 **Excel（`.xlsx`）**、**CSV**，以及可选导出 **Beancount** 纯文本账本格式。

### 3.10 WebDAV 同步与备份

- **工作模式（单机主力机备份与恢复）**：
  - 支持配置 WebDAV 服务器地址、用户名、密码及远程备份目录，提供连接测试。
  - **自动上传**：本地数据变更后防抖自动上传（如变更后 30 秒合并上传），并支持每日定时备份与手动立即备份。
  - **历史快照管理**：远端按时间戳保留多份备份快照（可配置保留最近 N 份，默认 10 份自动清理过期旧包），换机或误删时可查看快照列表并一键恢复（恢复前自动先在本地留一份安全回滚快照）。
- **端到端加密（强烈建议开启，默认支持开关）**：
  - 用户可设置独立的备份加密口令，备份包在本地加密后再上传至 WebDAV，防止网盘端明文泄露。
- **票据附件同步策略**：
  - 票据原图默认保存在本机应用私有目录，提供「同步票据原图至 WebDAV」可选开关，避免网盘空间与流量过度消耗。
